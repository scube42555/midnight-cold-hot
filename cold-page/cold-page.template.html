Midnight cold transfer

Sends unshielded NIGHT (or another unshielded token) from a wallet whose recovery phrase is typed only here. Use this page on an offline machine: it never connects to a network, and its security policy forbids it. It builds and signs the transfer from a snapshot of the wallet's coins made on the online (hot) machine; a sponsor wallet there pays the fee and submits. It does the work of cold-export-public and cold-transfer.

Reminder: make sure this machine is offline (cable unplugged, Wi-Fi and Bluetooth off). The browser reports a network link, but browsers say that whenever any network adapter is up, so it cannot tell whether the machine can actually reach the internet.
